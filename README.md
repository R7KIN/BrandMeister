# BrandMeister

<img width="921" height="181" alt="Screenshot 2026-08-28 174047" src="https://github.com/user-attachments/assets/9fdad871-aee6-4df3-a38c-be85533acda0" />

**BrandMeister (BM)** — это крупнейшая в мире глобальная децентрализованная сеть серверов и коммутаторов, объединяющая цифровые радиолюбительские ретрансляторы, домашние хотспоты (MMDVM) и другие цифровые сети голосовой связи (прежде всего формата DMR). Сеть была создана международной командой радиолюбителей-разработчиков для решения проблемы разрозненности различных DMR-систем (таких как DMR+, MARC, Hytera). Сеть построена по распределенной (mesh-подобной) схеме с высокой отказоустойчивостью. Высокопроизводительные узлы, которые связывают все Master-серверы между собой и перенаправляют голосовые потоки по всему миру с минимальной задержкой. Голосовой трафик организуется через номера групп:

**TG 91** — международная англоязычная группа (Worldwide).

**TG 250xx** — региональные группы по областям и субъектам РФ.

**bm_top3_v2.sh** - скрипт для проверки быстродействия (скорости ответа) серверов brandmeister.network. Работоспособность проверена на 6.12.101+deb13-amd64 #1 SMP PREEMPT_DYNAMIC Debian 6.12.101-1 (2026-08-05) x86_64 GNU/Linux

Актуальный список серверов: https://brandmeister.network/#/masters
